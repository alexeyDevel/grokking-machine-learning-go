# Grokking Machine Learning in Go

Учебный репозиторий по книге Луиса Серрано "Грокаем машинное обучение".

Цель: писать примеры, упражнения и небольшие реализации алгоритмов на Go по мере чтения глав.

## Структура

- `cmd/chapterXX` - запускаемые примеры для конкретных глав.
- `internal/chapterXX` - код алгоритмов и вспомогательные функции.
- `data` - небольшие учебные наборы данных.
- `notes` - краткие заметки по главам.

## Запуск

```bash
go run ./cmd/chapter01
go run ./cmd/chapter03
go run ./cmd/india_housing
```

## План

- Глава 1: базовые идеи машинного обучения и простой классификатор.
- Глава 3: линейная регрессия для учебного housing dataset.
- India Housing: прикладной Go-пайплайн для прогноза цен на жильё в Индии.
- Следующие главы: добавлять отдельные пакеты и команды по мере чтения.
